# Icon sources

Provenance and distribution status: see `../THIRD_PARTY_NOTICES.md`.

## Font Awesome Solid

`font-awesome-solid/` contains the pinned metadata and license for the active interface icons and folder picker.

Regenerate `modules/font-awesome.js` with `node scripts/generate-font-awesome.mjs`.

## Extension icon candidates

`extension-candidates/` contains the source options considered for the extension icon. `bookmark.svg` is the selected artwork and was exported to the 16, 48, and 128 px PNG files referenced by the manifest.

## UI icon shortlist

`ui-icons/` contains the source shortlist used during the interface icon migration. The running extension uses the generated Font Awesome registry.
